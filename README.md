#Network Shield Hacking Simulation Terminal

##About project 
The application is a terminal-based cybersecurity cryptography simulation game developed with Python. The game simulates corporate command line mainframe breaching puzzles, in which the player evaluates patterns and matches encrypted clusters with a limited number of attempts.

##Features
Object-oriented design: The scripts are structured with decoupled modules separating data logic, file structures, algorithm match tools, and terminal interfaces
Exception handling: The codebase implements extensive user-input filters to block invalid characters and prevent script execution errors.
Local file storage: The tool writes the active run's terminal logs to the local file system disk array for history recording purposes.

##Requirements
The application is primarily developed in Python and utilizes the language's standard libraries.

Programming language: Python 3.x
External Dependencies: random and io/os utilities for algorithmic cryptography simulation and file system access respectively.

##How to install
Clone this repository or download the ZIP package with source files and open a terminal in the working directory. Run the following command to start the application:
bash
python main.py

##How to test


Launch the program and select option 1 in the master directive dashboard panel. Next, enter a non-sensical word to test the invalid string error-handling mechanism. Select options guessing the key encryption letters from the array grid list to see the letter-matching calculation algorithm in action. Once the security hack round is complete, return to the master panel, select option 2 and ensure that the metrics were saved to the local file logs.
